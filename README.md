# 蚕室夜视 · 熟蚕比例巡检

一个纯前端 TypeScript/Vite 应用：八路蚕匾监控同时接入，使用 **WebGL2** 完成局部运动对齐、多帧稳健叠加降噪、节能灯/红外色彩校正和平场拉平，使用 **Web Worker** 完成熟蚕分割、跟踪、透光/颜色分类与比例统计，并在比例越过阈值时通过页内、声音和浏览器通知提醒蚕农。

## 运行

```bash
npm install
npm run dev
```

打开终端输出的本地地址（默认 http://127.0.0.1:5173 ；若端口占用，Vite 会选择后续端口）。

生产构建与本地预览：

```bash
npm run build
npm run preview
npm test
```

## 页面

- **监控接入** `#/access`：八路合成夜间真值信号、USB/本机摄像头、视频网关 URL、单路/全部 CFL↔IR 切换、实时 FPS/GPU/Worker 状态。
- **降噪校色** `#/enhance`：处理前后并排画面、4 帧运动补偿叠加、8×8 局部 SAD 运动估计、降噪/平场/锐化参数、运动矢量块显示、噪声/环纹能量/切换色差指标。
- **熟蚕比例** `#/ratio`：八路校正画面与检测框、熟蚕/未熟蚕计数、比例条、阈值线、比例曲线、合成人工真值对照、误差表和灯光×蚕龄数据集矩阵。
- **提醒设置** `#/alerts`：全局/逐匾阈值、冷却时间、声音、系统通知、可选 Webhook、提醒确认和历史记录。

设置与提醒记录保存在 `localStorage`。

## 合成真值夜间画面

`src/sim/SyntheticSilkwormScene.ts` 在浏览器中按通道种子实时合成 224×168 监控帧：

- 五龄初、五龄中、五龄末三种蚕龄和不同熟蚕比例；
- 节能灯绿黄响应、红外补光红紫/灰度响应、自动或手动 CFL↔IR 切换；
- 灯位距离造成的近亮远暗、平场衰减；
- 光子/读出噪声、热点、行曝光波动；
- 每条蚕独立爬行、正弦体态、体节环纹、熟蚕金色透光核心和强反光；
- 每帧输出蚕体框、熟蚕标签、数量、灯光模式和灯光混合系数。

`src/sim/datasetMatrix.ts` 额外生成“3 种蚕龄 × 节能灯/切换中间帧/红外”的样本矩阵。

## 处理流水线

### WebGL2

`src/processing/WebGLStackRenderer.ts` 为每路通道维护环形校正纹理：

1. **色彩校正 Pass**：黑电平偏移、白平衡增益、3×3 色彩矩阵、曝光/Gamma、饱和度、IR 亮度伪彩映射、灯位平场校正。
2. **运动估计 Pass**：在 28×21 个 8×8 块上用 SAD 十字patch搜索前后帧局部位移；缓慢爬行的蚕得到独立运动向量，静止蚕匾背景向量趋近于零。
3. **对齐叠加 Pass**：按局部运动向量把历史帧反向对齐到当前帧；色差过大的边缘/环纹像素自动降权，避免错位平均造成拖影、重影。
4. **锐化/矢量 Pass**：Unsharp Mask 恢复体节环纹；可选显示运动块和向量热力。

所有通道共享一个 WebGL2 context，顺序处理并 `readPixels` 到 Worker，避免八路各开一个 GL context。

### Web Worker

`src/workers/detection.worker.ts` 每路一个 module worker；`src/workers/detect.ts` 包含纯 CV/统计逻辑，可在 Node/Vitest 中直接测试：

- 2×2 平均降采样；
- 亮度直方图自适应阈值 + 积分图局部背景反差；
- 暖黄色/高反光/透光特征；
- 形态学闭运算和开运算；
- 8 邻接连通域、PCA 伸长度/长度/面积过滤；
- 邻近断裂片段合并；
- 最近质心多目标跟踪、熟蚕分数 EMA 和强特征投票；
- 蚕龄/灯光校准模型 `ratioCalibration.ts`。

Worker 返回检测框、计数、比例和耗时；主线程只负责绘制。

## 验收设计对应

1. **无拖影/重影、可见环纹**：局部运动对齐而非整帧平均；历史帧按匹配误差稳健加权，错误向量会被拒绝；最后一步锐化环纹。降噪页提供噪声指数和高频环纹能量对照。
2. **比例误差**：合成帧携带精确人工盘检真值，比例页逐匾显示估计值、真值和百分点误差；`npm test` 覆盖分割/比例和校准边界。浏览器长时间运行后，跟踪投票会进一步稳定比例。
3. **八路 ≥5 FPS**：默认每路目标 6 FPS，224×168 低分辨率、单 GL context、单运动向量 Pass、每两个通道让出主线程。真实带 GPU 的 Chrome/Edge 性能最佳；软件渲染/无头 SwiftShader 会明显更慢。
4. **CFL→IR 无跳变**：两种灯光分别使用标定色彩矩阵和 IR 伪彩曲线，并通过相同平场/Gamma 基准输出；页面显示相邻帧加权 RGB 跳变和累计最大跳变。
5. **并排查看**：降噪校色页始终保留原始夜拍和 WebGL2 处理结果两大画面。

## 真实摄像头/NVR

浏览器不能直接播放 RTSP。USB/本机摄像头可在“监控接入”中单路授权接入；RTSP/NVR 请先通过媒体网关转成 WebRTC、HLS 或 MJPEG，再使用视频网关 URL。生产环境建议为网关地址配置 HTTPS/WSS。

## 浏览器验证脚本

仓库包含可选的 Playwright Core 验证脚本，使用本机 Chrome：

```bash
npm run build
npm run preview -- --port 4180
VERIFY_URL=http://127.0.0.1:4180/ node scripts/verify-browser.mjs
```

脚本会输出八路 FPS、检测比例、真值误差、控制台错误，并把四个页面截图写入 `screenshots/`。
